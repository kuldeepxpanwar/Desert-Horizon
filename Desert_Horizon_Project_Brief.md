## UI Rules

-   Large whitespace
-   Rounded corners (16--24px)
-   Soft shadows
-   Glass effect only on booking card
-   No clutter

## Animations (Keep Minimal)

-   Hero fade-in
-   Text reveal
-   Smooth scrolling
-   Image hover zoom
-   Card lift on hover
-   Counter animation
-   Navbar blur on scroll
-   Section reveal
-   Button ripple

Avoid: - Heavy 3D - Loud effects - Excessive parallax
