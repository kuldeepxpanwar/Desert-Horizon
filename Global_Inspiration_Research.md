# PRIMARY DESIGN GOAL

Create a website that feels like an international luxury travel brand.

It should NOT look like a typical local desert camp website.

Target feeling:

-   Premium
-   Cinematic
-   Editorial
-   Elegant
-   Authentic Rajasthan
-   Luxury Hospitality
-   Adventure
-   Fast
-   Mobile First

------------------------------------------------------------------------
